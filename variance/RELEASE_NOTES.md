# 1.0.1 release notes

This is the reviewed variance packaging revision published with repository v1.2.0. Mathematical content is version 1.0.0.

Changes:

- Restored the exact prior MIT license and adaptation credit.
- Added explicit original-contribution and third-party license scope.
- Removed all 18 license-unverified refinement snapshots and the historical
  raw GitHub API/PR inventory; preserved their immutable reference metadata.
- Added a hash-checked external source-cache fetcher and disposable-overlay
  replay wrapper. Inventory-only and full replay have distinct outcomes.

  arithmetic/mutation programs. Added independent grid/matrix/activity
  replay and packaging failure controls.
